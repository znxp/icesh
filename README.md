# Anomali Snapshot Utility

Python utility for Anomali Snapshot API creation, polling, downloads, SHA256 verification, streaming JSON parsing, merge, dedupe, and duplicate reporting.

## Dependency

```powershell
pip install -r requirements.txt
```

`ijson` is required for streaming large JSON array snapshot files.

## Important credential note

Do not commit real API keys to `config/settings.json`. If an API key was ever pasted into a screenshot, chat, ticket, or repository, rotate it before use.

## Configuration

Edit `config/settings.json`:

```json
{
  "api": {
    "base_url": "https://api.threatstream.com/api/v1/snapshot/",
    "username": "your_user@example.com",
    "api_key": "REPLACE_WITH_NEW_API_KEY"
  },
  "snapshot": {
    "intel_version": 1,
    "custom_config": {
      "filter": "state=\"active\" AND confidence>=50 AND date_first>=2026-01-01T00:00:00",
      "whitelist": {"type": ["ip", "domain"]},
      "format": "json_v2",
      "chunk_size": "100MB",
      "use_org_whitelist": true
    }
  }
}
```

The POST body generated by `snapshot-create` is:

```json
{
  "intel_version": 1,
  "custom_config": {
    "filter": "...",
    "whitelist": {"type": ["ip", "domain"]},
    "format": "json_v2",
    "chunk_size": "100MB",
    "use_org_whitelist": true
  }
}
```

## Local merge test

```powershell
python main.py merge --fresh --input-dir downloads --output-dir output --config config/settings.json
```

Expected with bundled sample file:

```text
processed=6 unique=3 duplicates=3 errors=0
```

## API smoke test

After rotating/replacing your API key:

```powershell
python main.py test-auth --config config/settings.json
```

## Create snapshot

```powershell
python main.py snapshot-create --config config/settings.json
```

## Wait for snapshot

```powershell
python main.py snapshot-wait --snapshot-id 8555784 --config config/settings.json
```

## Download and verify snapshot files

```powershell
python main.py snapshot-download --snapshot-id 8555784 --download-dir downloads/raw --config config/settings.json
```

## End-to-end sync

```powershell
python main.py sync --fresh --download-dir downloads/raw --output-dir output --config config/settings.json
```

## Fresh and resume

Use `--fresh` to reset SQLite state and generated output for a clean run. It preserves `logs/` and `downloads/raw/`. Use `--resume` only when continuing an interrupted run.


### Windows note for `--fresh`

`--fresh` resets the SQLite state database and generated output. It does **not** delete `logs/` or `downloads/raw/` because Windows can lock those folders via Explorer, editors, antivirus, or indexing and raise `WinError 5: Access is denied`.

For `sync`, downloaded API files are written into a snapshot-specific subfolder such as `downloads/raw/snapshot_8555784/`, and the merge step processes only that subfolder. This avoids mixing stale raw downloads with the current run while still preserving existing raw data.


## Updated `--fresh` cleanup behavior

`--fresh` removes:

```text
state.db
output/*
downloads/temp/*
downloads/verified/*
```

`--fresh` preserves:

```text
config/
logs/
downloads/raw/
```
